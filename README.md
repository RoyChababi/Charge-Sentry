# ChargeSentry demo app

Presentation demo for ChargeSentry (McGill BUSA 465, Team #2). Everything lives in one file, `index.html`. Double-click it to run. It works fully offline with no installs, and all data is simulated.

The stage is designed for 1920 × 1080 and scales to fit any window (tested at 1366 × 768).

## Presenter shortcuts

| Key | Action |
|---|---|
| P | Show / hide presenter panel (or the gear, top right) |
| Space | Play / pause the 90-second pitch script |
| 1 | Start charge |
| 2 | Heat trend (warning at 45 °C) |
| 3 | Cooking vapour (ambient filter, no cut) |
| 4 | Off-gas event (full alert, power cut) |
| 5 | Charger fault (current anomaly cut) |
| 6 | Timer stop |
| 0 | Acknowledge / resolve the active alert |
| R | Reset demo |
| + / − | Speed 1×, 5×, 20×, 60× |
| M | Sound on / off |
| C | Captions on / off |
| F | Fullscreen |

Sound starts after the first click or key press (browser autoplay rule). The script runs at 1× so its timing matches the pitch.
